# คู่มือแคปภาพอัปเดตตัวเลขสแนปช็อต (bitcoin-from-zero)

ไฟล์นี้ชั่วคราว ลบได้เมื่ออัปเดตเสร็จ ทำเป็นงานปิดท้ายหลังเนื้อหานิ่งแล้ว

## กติกาข้อเดียวที่สำคัญที่สุด

**แคปทุกภาพในวันเดียวกัน ภายในเวลาไม่เกินหนึ่งชั่วโมง** ถ้าความยากกับอัตราแฮชมาคนละวัน
เลข "เดาต่อบล็อก" จะไม่ตรงกับ "สิบนาทีต่อบล็อก" แล้วบทความจะขัดกันเองโดยที่ไม่มีใครจับได้

## เก็บไว้ที่ไหน ตั้งชื่อว่าอะไร

โฟลเดอร์: `docs/snapshots/2026-mm-dd/` (ใช้วันที่ที่แคปจริง)

ห้ามเก็บใน `public/` เพราะทุกอย่างใน `public/` จะถูกคัดลอกขึ้นเว็บจริง ภาพชุดนี้เป็นหลักฐาน
สำหรับเราเอง ไม่ใช่ของที่ต้องเสิร์ฟให้คนอ่าน

ชื่อไฟล์: `<ลำดับ>-<ชื่อค่า>.png` เรียงตามตารางข้างล่าง เช่น `01-tip-height.png`
ลำดับนำหน้าทำให้เรียงในโฟลเดอร์แล้วตรงกับลำดับที่ต้องกรอกลงโค้ดพอดี

## ภาพแบบไหนถึงเรียกว่าใช้ได้

1. **ต้องเห็นตัวเลขเต็ม ไม่ถูกย่อ** ถ้าเว็บโชว์ 899.5 EH/s แต่ค่าเต็มอยู่ในทูลทิป ให้เอาเมาส์ชี้
   ค้างไว้แล้วแคปทั้งทูลทิป ตัวเลขที่ถูกปัดมาแล้วใช้ไม่ได้กับค่าความยาก ซึ่งต้องการหลักหน่วย
2. **ต้องเห็น URL ของเว็บในภาพ** แคปทั้งหน้าต่างเบราว์เซอร์รวมแถบที่อยู่ ไม่ใช่ครอปเฉพาะตัวเลข
   เพราะหกเดือนถัดไปจะไม่มีใครรู้ว่าเลขนี้มาจากหน้าไหน
3. **ต้องเห็นนาฬิกาหรือวันที่** ถ้าเว็บมีเวลากำกับในหน้าก็พอ ถ้าไม่มี ให้แคปรวมนาฬิกามุมจอ
4. **หน่วยต้องอยู่ในภาพ** โดยเฉพาะขนาดสมุด ที่หน้ากราฟสลับระหว่าง MB กับ GB ได้
   ตัวแปรในโค้ดชื่อ `CHAIN_MB` และคาดหวังหน่วย MB
5. อ่านออกก็พอ ไม่ต้องสวย ไม่ต้องครอป ไม่ต้องวาดกรอบแดง

## ตรวจก่อนถือว่าจบ

- ทุกภาพแสดงวันเดียวกัน
- `npm run check` `npm run lint` `npm run build` ผ่าน
- เปิดหน้าจริงแล้วไล่ดูว่าเลขในย่อหน้า ในภาพ และในตาราง เปลี่ยนตามกันหมด
  โดยเฉพาะบันไดหน่วยอัตราแฮช (ดูข้อ 9 ในโน้ตรีวิว ต้องแก้บันไดก่อนอัปเดตเลข ไม่ใช่หลัง)
- ทุกกล่อง ExplainNumber ยังคำนวณกลับได้ตรงกับค่าที่แสดง
